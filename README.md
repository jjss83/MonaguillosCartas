# MonaguillosCartas

## Juego de Cartas para Monaguillos

Este es un juego educativo simple donde los jugadores aprenden el orden correcto de los artífices (elementos litúrgicos) que los monaguillos utilizan durante la Santa Misa.

### Cómo jugar

1. Abre `index.html` en tu navegador web
2. Verás 8 cartas con diferentes artífices barajadas
3. Arrastra las cartas al área "Orden correcto" en la secuencia correcta según se usan en la Misa
4. Haz clic en "Verificar Orden" para comprobar si el orden es correcto
5. Si aciertas, recibirás 100 puntos
6. Usa el botón "Reiniciar" para empezar de nuevo

### Artífices incluidos (en orden)

1. **Cruz procesional** ✝️ - Se lleva al inicio de la procesión
2. **Velas o ciriales** 🕯️ - Iluminan la procesión y el altar
3. **Vinajeras** 🍶 - Contienen el vino y el agua para la Eucaristía
4. **Lavabo** 💧 - Agua y toalla para el lavado de manos del sacerdote
5. **Campana** 🔔 - Se toca en momentos importantes de la Misa
6. **Incensario** 🔥 - Para el incienso en ceremonias solemnes
7. **Misal** 📖 - Libro litúrgico con las oraciones de la Misa
8. **Patena y Cáliz** 🍷 - Para el pan y el vino consagrados

### Instalación

No requiere instalación. Simplemente abre el archivo `index.html` en cualquier navegador web moderno.

```bash
# Clona el repositorio
git clone https://github.com/jjss83/MonaguillosCartas.git

# Abre el archivo en tu navegador
cd MonaguillosCartas
open index.html  # En macOS
# o simplemente haz doble clic en index.html
```
